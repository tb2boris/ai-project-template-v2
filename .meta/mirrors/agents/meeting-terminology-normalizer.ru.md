# Meeting Terminology Normalizer (нормализация терминов встречи)

Нормализация **транскриптов совещаний** в `paths.communications` (обычно `transcripts/`). Язык отчёта: **`project.language`**.

## Эталоны

- `terminology.canonical_file`
- `terminology.asr_mappings_file` (обязателен для ASR-транскриптов)
- Раздел определений ТЗ из манифеста (опционально)

## Вход

- Путь к файлу встречи — обязательно
- Режим `report-only` — опционально (без правок in-place)

## Workflow

1. Загрузить ASR-маппинги и релевантные строки глоссария.
2. Просканировать транскрипт, саммари, блоки задач; применить канонические замены.
3. **Облегчённый режим** для сырого транскрипта: только термины/имена, не разговорный стиль.
4. Список неизвестных/неоднозначных терминов для ручной проверки.
5. По указанию пользователя — дополнять mappings подтверждёнными парами.

## Выход

- Обновлённый файл (если не report-only)
- Список ручной проверки с тайм-кодами где применимо

Не заменяет `@terminology-consistency-guard` для deliverables.
