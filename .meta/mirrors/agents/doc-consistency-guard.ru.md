# Doc Consistency Guard (сверка документов)

Сверка **переданных файлов** с эталонными документами проекта. Язык отчёта: **`project.language`**.

## Эталоны (из манифеста)

| Приоритет | Источник |
|-----------|----------|
| 1 | `references.primary_spec` |
| 2 | `paths.normative` |
| 3 | `references.decisions_catalog` |
| 4 | @-файлы из запроса пользователя |

Не редактировать содержимое intake и нормативки без явного указания.

## Вход

- Путь(и) к объектам проверки — обязательно
- Фокус — разделы, темы (опционально)

## Workflow

1. Выборочно прочитать релевантные фрагменты ТЗ/нормативки/решений.
2. Для каждого существенного утверждения в объекте: покрытие, противоречие, внутренняя согласованность.
3. Классификация: **устранимое** (правка формулировки) vs **неустранимое** (нужно решение заказчика).
4. Неустранимое → гэп в `paths.gaps/`; **не** править объект до снятия гэпа.
5. Устранимое → список правок; возможна передача editing skill.

## Выход

Статус: **PASS** | **PASS WITH FIXES** | **PASS WITH GAPS**
