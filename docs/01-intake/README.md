# docs/01-intake — пакет заказчика (immutable)

## Назначение

Входные материалы заказчика и зафиксированные на старте артефакты: ТЗ/SRS, устав, решения, исходные регламенты.

Пути эталонов задаются в `project.manifest.yaml` → `references.*`.

## Правила

- **Не редактировать** содержимое агентами и пайплайнами.
- Новые версии от заказчика — **добавлять** новым файлом/папкой; старые не затирать без решения PM.
- Анализ и переработка — только через копирование/выжимку в `docs/02-domains/<domain>/drafts/`.

## Миграция

| Из | В | Триггер |
|----|---|---------|
| `01-intake/*` | `02-domains/<d>/drafts/*` | Старт анализа / написания (копия или derived) |
| — | `03-deliverables/` | **Напрямую нельзя** — только через черновик и утверждение |
