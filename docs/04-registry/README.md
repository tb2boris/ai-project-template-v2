# docs/04-registry — реестры и служебные отчёты

## Назначение

Машинно и аналитически сопровождаемые артефакты:

| Подпапка / файл | Назначение |
|-----------------|------------|
| `file-registry.md` | Сводный реестр структуры (пишет `@structure-indexer`) |
| `gaps/` | Зафиксированные противоречия и нехватка данных |
| `compliance-reports/` | Отчёты `/compliance-check-pipeline` |
| `meetings/` | Excel/JSON отчёты по задачам встреч |
| `terminology/` | Канонические термины и ASR-маппинги |
| `customer-questions.md` | Опционально (manifest `question_tracker`) |

## Миграция

- Сюда **пишут** пайплайны и guards; это не замена `03-deliverables`, кроме случая, когда deliverable *есть* реестр.
- Закрытие гэпа может породить правку в `02-domains/.../drafts/` или обновление deliverable — но сам gap-файл обычно остаётся как история.
