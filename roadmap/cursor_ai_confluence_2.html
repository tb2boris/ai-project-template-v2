Безопасность ИИ-инструменты

Проблема: Риск утечки ПДн

"Прямая отправка документов из Confluence в облачные модели ИИ через Cursor нарушает закон 152-ФЗ и требования ИБ."

Наше решение:

Создание промежуточного контура деперсонализации (обезличивания) данных.

Двухконтурная модель данных

Контур А (Raw)

Сырые данные

Confluence с ПДн сотрудников и клиентов.

Скрипт dp152
→ → →
Контур Б (Safe)

Обезличенные данные

Доступны для MCP-сервера и Cursor AI.

Важно: Искусственный интеллект "видит" только Контур Б. Информация в Контуре Б не содержит имен, телефонов и адресов.

Сервис деперсонализации

Скрипт dp152

  • 1

    Обнаруживает ФИО, адреса и реквизиты.

  • 2

    Заменяет их на уникальные токены.

  • 3

    Сохраняет связь документов для обратной синхронизации.

100%
Автоматизация анонимизации

Confluence MCP Server

Протокол контекста модели (MCP) — это "глаза" искусственного интеллекта в вашей корпоративной среде.

Безопасность

Работает только в режиме чтения из Контура Б.

Конвертация

Мгновенно переводит страницы Confluence в формат Markdown.

Поиск

Позволяет ИИ выполнять семантический поиск по всей базе знаний.
