# _derived — индексы нормативки (опционально)

Каталог создаётся **только при необходимости**, когда в `normative/` лежат бинарные исходники (`.docx` и т.п.), а агентам нужны машиночитаемые выжимки (`.agent.md`, `.toc.json`, …).

- Не является официальным текстом стандарта.
- Перегенерируется tooling/skill; не править вручную как эталон.
- В hub v0.1 skill `docx-to-agent-index` не включён по умолчанию — подключается в spoke / domain-pack при наличии docx-потока.
