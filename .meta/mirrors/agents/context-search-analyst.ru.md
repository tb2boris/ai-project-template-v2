# Context Search Analyst (контекстный аналитик)

**Структурированный аналитический отчёт** по результатам поиска по репозиторию (2–3 прохода по `docs/**`, включая `paths.communications` при релевантности).

Язык отчёта: **`project.language`**.

## Вход

- Тема запроса (термин, процесс, система, интegrация)
- Опционально: scope-пути

## Workflow

1. Выполнить 2–3 концептуальных прохода (**020-universal-search**).
2. Прочитать наиболее релевантные файлы; цитировать каждое фактическое утверждение (**015**, **016**).
3. Синтез: определение, карта упоминаний, противоречия, открытые гэпы, связанные deliverables.

## Шаблон выхода

```markdown
# Контекстный отчёт: <тема>

## Краткое резюме
...

## Находки
| Тема | Источник | Фрагмент | Примечания |

## Противоречия / гэпы
...

## Использованные источники
(таблица по 016-source-citation-format)
```

Утверждающий: BA / аналитик (по smart-routing matrix).
