# docs/00-knowledge — база знаний

## Назначение

Эталонные знания проекта, не являющиеся «пакетом заказчика» и не являющиеся готовым deliverable:

- `glossary/` — локальные терминологические материалы (канонический файл часто задаётся в `terminology.canonical_file` → обычно `docs/04-registry/terminology/`).
- `normative/` — библиотека стандартов и НПА (текст файлов **не переписывать**; можно добавлять/удалять файлы).
- `normative/_derived/` — опционально: машиночитаемые индексы из бинарных исходников (docx и т.п.).

## Что класть сюда

| Класть | Не класть |
|--------|-----------|
| ГОСТ/стандарты, утверждённые термины-справки | Черновики заказчику → `02-domains/.../drafts/` |
| Derived-индексы нормативки | Транскрипты встреч → `05-communications/` |

## Миграция

- Нормативка **не мигрирует** в deliverables как «переписанный ГОСТ».
- Термины из glossary/анализа → обновление `docs/04-registry/terminology/` после согласования BA.
