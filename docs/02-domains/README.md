# docs/02-domains — работа по предметным доменам

## Назначение

Основная зона создания документов. Структура:

```
02-domains/
  <domain-id>/
    drafts/          # черновики до утверждения
    README.md        # опционально: границы домена
    ...              # прочие рабочие материалы домена
```

Имя `<domain-id>` — латиница/kebab-case (пример: `migration`, `integrations`, `testing`).

## Что класть сюда

- Черновики стратегий, описаний, протоколов согласования (внутренние).
- Промежуточные таблицы и выжимки из встреч (не сырые транскрипты).

## Миграция

| Из | В | Триггер |
|----|---|---------|
| `01-intake` / `05-communications` | `02-domains/<d>/drafts/` | Старт работы над документом |
| `drafts/` | `03-deliverables/` | Утверждение BA/PM (+ compliance при включённом packs) |
| `drafts/` | `04-registry/gaps/` | Обнаруженные противоречия / нехватка данных |

Перед публикацией в deliverables: `/compliance-check-pipeline` (если `compliance.enabled`).
