# docs/06-quality — качество и приёмка

## Назначение

| Подпапка | Назначение |
|----------|------------|
| `acceptance/` | Критерии приёмки, чеклисты UAT |
| `eval/golden-set/` | Эталонные кейсы для smoke/eval пайплайнов шаблона |

## Миграция

- Критерии приёмки могут начинаться как draft в `02-domains/` и после утверждения копироваться сюда или в `03-deliverables/` (если это документ заказчику).
- Golden-set — внутренний контур шаблона/spoke; не путать с customer deliverables.
