# docs/03-deliverables — утверждённые результаты

## Назначение

Документы, которые можно передавать заказчику или считать официальной версией в проекте: стратегии, методики, письма (если применимо), согласованные спецификации-проекции.

## Правила

- Попадают сюда **только** после human approval.
- Предпочтительно сохранять след: ссылка на исходный draft / версию в `02-domains`.
- Письма заказчику (если ведутся в репо) — подпапка `letters/` по соглашению команды.

## Миграция

| Из | В | Триггер |
|----|---|---------|
| `02-domains/**/drafts/` | `03-deliverables/` | Утверждение |
| `03-deliverables/` | `.archive/` | Замена мажорной версией (spoke policy) |

Не складывать сюда сырые транскрипты и незакрытые гэпы.
